PROJETO BIOCORPO pela turma Informática 2024 Manhã

Objetivo:
Desenvolver o design visual e a organização da interface do site educacional de Biologia,
com o objetivo de proporcionar uma experiência de navegação simples, intuitiva, organizada 
e agradável aos usuários.
O site apresentará uma imagem interativa do corpo humano, permitindo que os estudantes 
selecionem diferentes órgãos e consultem informações sobre suas características, funções e 
importância. O design deverá facilitar a identificação dos órgãos, a leitura dos conteúdos 
e a navegação entre as páginas.
O projeto tem como finalidade contribuir para o aprendizado dos estudantes por meio de uma 
interface visualmente atrativa, acessível e adequada ao público do Ensino Médio.
